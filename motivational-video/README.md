# The One-Hour Promise — 3D animated short film

**This is a 3D remake of the original motivational slideshow**, with scripted animated human characters and changing camera angles. The 10-minute timeline contains **24 moving 3D shots (25 seconds each)** across five modeled locations: a city street, repair shop, home, classroom, and rooftop.

Characters: Tara (repairer/inventor), Dev (student), Tara's mother, and a mentor. Original story about perseverance, failure and helping children study during electricity outages.

## What makes it animated?
- Four distinct recurring stylized 3D human models generated by React Three Fiber.
- Articulated hips, knees, shoulders, elbows and facial eyes/mouth.
- Frame-controlled walking, running, working, soldering, reading, talking, giving/receiving a lamp and celebrations.
- Camera tracking and orbital movements, lighting, city buildings, sparks, moving rain and a glowing solar lamp.
- Narrated story audio per chapter.
- **This is a procedural low-poly / stylized animation, NOT photorealistic motion-capture film.** The characters are modeled with primitives and will not have production-quality acting, dialogue lip sync, or natural skin/hair. For that upgrade, replace `Human.tsx` with licensed rigged GLB avatars and clips.

## GitHub Actions
1. Open [Actions → Render 3D cinematic film](https://github.com/hritik2899/Random-Pattern-Animations/actions/workflows/render-motivational-story.yml).
2. New feature-branch pushes automatically render a **12-second preview** showing Tara passing a lamp to Dev.
3. For the **10-minute film**, select **Run workflow**, choose this PR branch, and choose `full`.
4. Download the `cinematic-3d-preview` or `cinematic-3d-full` ZIP artifact from the successful workflow run.

The full video may take a long time to render on a GitHub CPU runner using software WebGL. The workflow has a 240-minute timeout and does not guarantee completion for slow runners. GitHub Actions limits, runner availability, and quotas apply.

## Local commands
Node.js 22+, Python 3.11+, ffmpeg, espeak-ng and browser dependencies required.

```bash
cd motivational-video
npm install
python -m pip install edge-tts
python scripts/voice.py
npx remotion browser ensure
npm run studio
npm run preview
npm run render
```

## Files
- `src/film/Human.tsx`: characters, rig-like procedural motion, expressions
- `src/film/World.tsx`: 3D environments, furniture, solar lamp
- `src/film/Scenes.tsx`: 24 shot plans, actor paths, cinematic cameras, weather
- `src/index.tsx`: Remotion preview and ten-minute film compositions
- `scripts/voice.py`: neural TTS with offline voice fallback
- `story.json`: 12 story chapters and narration
- `remotion.config.ts`: ANGLE renderer for CI WebGL

Unlike the earlier version, the new video uses actual 3D animated body actions rather than a sequence of static backgrounds and text slides.
